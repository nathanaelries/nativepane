There are **zero external Go modules and zero JavaScript dependencies**. There
are no bundled fonts, icons, images, converters, Office engines or CDNs. The N
mark and CSS interface are original. System fonts are provided by the browser OS.

The machine-readable package inventory and verbatim notices are generated by
`go run ./cmd/notices`. The generated THIRD_PARTY_NOTICES.txt is checked in for
the development toolchain. Docker regenerates it for the exact Linux build and
ships it at `/licenses/THIRD_PARTY_NOTICES.txt`, alongside our MIT LICENSE. The
collector rejects any external Go module and retains ancestor license files and
source copyright preambles from the packages compiled into the executable.
These upstream notices retain their original terms; we do not relicense Go MIT.
The collector includes ancestor notice files even when they describe disabled
build variants. In particular, retaining Go's conditional BoringSSL license file
does not mean BoringSSL is linked. The default build sets CGO_ENABLED=0 and does
not enable GOEXPERIMENT=boringcrypto.
